# 프린터 연결하기

앱의 **프린터 추가** 화면에서 순서대로 진행합니다.

1. **프린터 찾기:** **프린터 검색**을 누르세요. 목록에 없으면 IP 주소를 입력하고 **IP 주소 적용**을 누릅니다.
2. **모델 확인:** 발견된 프린터를 선택합니다. 자동 식별이 어렵다면 기기에 적힌 모델명을 확인하세요.
3. **드라이버 선택:** 추천 항목을 확인합니다. 필요한 경우 **제조사 공식 지원 페이지** 또는 **PPD 파일 선택**을 이용합니다.
4. **등록:** 프린터 이름을 확인한 뒤 **이 프린터 등록**을 누르고 실행 내용을 승인합니다.

검색은 프린터 설정을 바꾸지 않습니다. **패키지 설치·프린터 등록은 승인하기 전에는 실행되지 않으며**, 확인창의 **내용 복사** 버튼으로 실행 명령을 복사할 수 있습니다.

### 연결되지 않을 때

- 프린터 검색 결과가 없다면 프린터와 Chromebook의 네트워크 연결, 프린터 IP 주소를 확인하세요.
- **IPP Everywhere**는 장치에서 지원할 때 사용합니다. 지원이 불확실하다면 제조사 드라이버를 확인하세요.
- 등록된 프린터에서 인쇄가 안 된다면 **프린터 상태**와 **인쇄 대기열**을 확인하세요.
