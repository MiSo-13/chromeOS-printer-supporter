# 프린터 처음 연결하기

앱의 **프린터 추가** 메뉴에서 진행합니다.

## 1. 프린터 찾기

- **프린터 검색**을 누릅니다. 최초 1회 검색 작업 안내가 나타납니다.
- 목록에서 프린터를 선택합니다. 하나만 발견되면 자동 선택합니다.
- 프린터가 보이지 않으면 IP 주소(예: `192.168.1.20`)를 입력하고 **IP 주소 적용**을 누릅니다.
- IPP 연결이 안 될 때만 실제 장치가 지원하는지 확인한 후 Socket(9100)을 선택하세요.

검색 작업은 CUPS의 `lpinfo -v` 결과만 조회합니다. **패키지 설치, 등록, 인쇄를 하지 않습니다.**

## 2. 모델 확인

선택한 프린터의 모델과 지원 정보를 읽습니다. IPP가 직접 보고한 모델명과 검색 서비스의 추정 이름을 구별합니다.

- **우선 안내 모델**은 [지원 모델 안내](SUPPORTED_PRINTERS.md)에 기록되어 있습니다.
- 목록 밖 프린터도 IPP/CUPS 기반으로 계속 시도할 수 있습니다.
- 상세 기술 정보는 **상세 정보 보기**에서 확인합니다.

## 3. 드라이버 선택

가능하면 IPP Everywhere나 이미 설치된 CUPS 드라이버를 사용합니다. 목록에 없다면 제조사 공식 지원 페이지 또는 PPD 파일을 확인하세요.

시스템 패키지 설치가 필요한 경우 **설치 대상, 패키지명, 실행 명령, 설치 위치, 변경되는 내용**이 승인창에 표시됩니다. **내용 복사** 버튼이나 Ctrl+C로 기록할 수 있으며, **설치**를 누르기 전에는 실행되지 않습니다.

제조사 사이트의 압축파일/설치 스크립트는 앱에서 자동 다운로드·실행하지 않습니다.

## 4. 등록

프린터 이름과 드라이버를 확인한 후 **이 프린터 등록**을 누릅니다.

등록 전에 정확한 `lpadmin` 명령과 연결 URI가 표시됩니다. **내용 복사** 후 확인할 수 있으며, **등록**을 승인해야 새 CUPS 큐가 생성됩니다. 등록은 인쇄 명령을 실행하지 않습니다.

## 도움이 필요한 경우

- **사용 방법** 버튼: 언제든 4단계 안내창 열기
- **상세 정보 보기**: IPP 응답·추천 근거·설치 정보 확인
- **복사 가능한 안내창**: 검색, 시스템 패키지 설치, 드라이버 설치, 프린터 등록 전에 작업 확인
- CUPS 검색 권한 오류가 나오면 IP 직접 입력을 사용하거나 Crostini의 CUPS 권한을 확인하세요.
- 인증 또는 드라이버 지원이 확인되었다고 해서 Chromebook에서 실제 인쇄까지 보장되는 것은 아닙니다.
