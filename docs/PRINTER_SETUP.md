# 프린터 연결하기

앱 왼쪽의 **프린터 추가**를 엽니다.

1. **프린터 찾기:** **프린터 검색**을 누르세요. CUPS 검색으로 실제 IPP 주소를 확인하지 못한 경우 `ippfind`로 IPP/IPPS 프린터를 추가로 찾습니다. 그래도 검색되지 않으면 IP 주소를 직접 입력할 수 있습니다.
2. **모델 확인:** 프린터를 선택하면 앱이 모델과 IPP 지원 여부를 확인합니다.
3. **드라이버 자동 탐색:** IPP Everywhere → 설치된 CUPS 드라이버 → APT 패키지 → 제조사 공식 지원 페이지 순으로 확인합니다.
4. **필요한 드라이버 설치:** 설치 가능한 APT 드라이버가 있으면 패키지·출처·명령을 보여줍니다. **설치**를 승인하면 다운로드와 설치를 진행합니다.
5. **설치 결과 확인:** 앱이 설치 후 CUPS에서 해당 모델을 다시 찾습니다. 모델이 없거나 여러 개라면 안내에 따라 확인해 주세요.
6. **프린터 등록:** 사용할 드라이버를 확인하고 **이 프린터 등록**을 누릅니다. 등록도 별도 승인이 필요합니다.

검색만으로는 패키지를 설치하거나 인쇄하지 않습니다. 설치·등록 확인창의 내용은 복사할 수 있습니다.

## 설치나 프린터 등록에 실패했다면

앱에 **연결 문제 해결** 영역이 나타납니다.

1. **드라이버 다시 확인:** 설치 명령을 재실행하지 않고 IPP·CUPS·APT 상태를 새로 조회합니다. 설치 가능한 패키지가 다시 확인되면 설치 내용을 확인하고 승인해 재시도할 수 있습니다.
2. **설치된 CUPS 드라이버 선택:** 실제 프린터 모델과 일치하는 후보가 있을 때만 사용합니다. 목록에서 모델을 직접 선택하세요.
3. **IPP 연결 시도:** 프린터가 IPP Everywhere 지원 정보 또는 호환 가능성을 보고한 경우에만 선택할 수 있습니다. 실제 출력 여부는 별도 확인이 필요합니다.
4. **PPD 파일 선택:** 제조사에서 받은 호환 PPD가 있다면 직접 지정할 수 있습니다. 공식 지원 페이지도 확인할 수 있습니다.

**다른 모델의 드라이버를 자동 설치하거나 반복 설치하지 않습니다.** 연결 방식을 바꾼 뒤 프린터를 등록할 때는 다시 확인창이 표시됩니다.

## 프린터가 검색되지 않거나 모델을 모를 때

**프린터가 안 보여요** 버튼에서 확인 방법을 볼 수 있습니다.

- 프린터와 Chromebook이 같은 네트워크에 연결돼 있는지 확인하세요.
- **모델명:** 프린터 본체 앞면·뒷면의 제품 라벨을 확인하세요.
- **IP 주소:** 프린터 네트워크 설정에서 IPv4 또는 IPv6 주소를 확인하세요. IPv6 링크 로컬 주소는 지원하지 않습니다. Chromebook 설정의 프린터 목록 또는 공유기 연결 장치 목록도 참고할 수 있습니다.
- **IP 주소 적용:** 먼저 IPP를 시도하고, 프린터가 암호화 IPP를 제공한다면 **IPPS**를 선택할 수 있습니다. 기본 IPP 경로는 `/ipp/print`, 기본 포트는 631입니다. 기기 설명서에 다른 경로(`/ipp/printer`, `/printers/queue` 등)나 포트(예: 443)가 명시되어 있다면 해당 값을 직접 입력하세요. Socket 연결은 기본 포트 9100입니다.
- 경로·포트는 사용자가 지정한 값만 사용합니다. 앱이 주변 IP 대역이나 여러 포트·경로를 자동으로 반복 조사하지는 않습니다.
- ChromeOS 프린터 목록과 Linux(Crostini)의 CUPS 프린터 목록은 별개입니다. USB 프린터는 Linux 접근 권한이 제한될 수 있습니다.

검색은 **버튼을 눌렀을 때만** 실행되며, 네트워크 전체 IP 주소를 순회하거나 자동으로 프린터를 등록하지 않습니다. 모델 정보를 실제 프린터에서 읽지 못하면 기기명만으로 호환 드라이버를 추정하지 않습니다.

## 드라이버를 찾지 못했다면

- 장치가 IPP Everywhere를 지원하지 않으면 추가 드라이버가 필요할 수 있습니다.
- 제조사 공식 지원 페이지나 이미 보유한 PPD 파일을 확인하세요.
- **Samsung SL-M2030W:** x86_64 Chromebook에서는 확인된 IPP 모델에 대해 삼성 공식 Linux 드라이버를 승인 후 다운로드·설치할 수 있습니다. ARM은 자동 설치가 지원되지 않습니다.
- 인쇄가 안 되면 **프린터 상태**와 **인쇄 대기열**을 확인하세요.
