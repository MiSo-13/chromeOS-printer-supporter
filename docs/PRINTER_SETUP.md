# 프린터 연결하기

앱 왼쪽의 **프린터 추가**를 엽니다.

1. **프린터 찾기:** **프린터 검색**을 누르고 목록에서 프린터를 선택합니다.
2. **검색되지 않나요?** 프린터 IP 주소를 입력하고 **IP 주소 적용**을 누릅니다. 일반적으로 연결 방식은 **IPP**부터 시도합니다.
3. **드라이버 선택:** 자동 추천 항목을 확인합니다. 추천이 없다면 제조사 지원 페이지에서 드라이버를 확인하거나 가지고 있는 PPD 파일을 선택합니다.
4. **프린터 등록:** 사용할 이름을 확인하고 **이 프린터 등록**을 누릅니다.

드라이버 설치나 프린터 등록이 필요한 경우 **실행할 작업을 먼저 보여줍니다.** 내용을 복사하거나 취소할 수 있습니다.

## 연결이 안 될 때

- 검색 목록이 비어 있다면 Chromebook과 프린터의 네트워크 연결 및 IP 주소를 확인하세요.
- **IPP Everywhere**가 지원되지 않는 프린터는 제조사 드라이버나 호환 PPD가 필요할 수 있습니다.
- 등록했는데 출력되지 않는다면 **프린터 상태** 또는 **인쇄 대기열**의 오류를 확인하세요.
